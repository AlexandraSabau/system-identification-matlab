# System Identification in MATLAB

## Description
This project focuses on system identification techniques applied to electrical systems and a DC–DC converter,
using MATLAB and Simulink. Both time-domain and frequency-domain methods are implemented and validated.

## Project Overview
The project is structured into three main parts:

- **Part 1:** Second-order system identification from step response using linear regression
- **Part 2:** Frequency-domain identification using Chirp (VCO) excitation
- **Part 3:** Offline identification of a DC–DC converter using SPAB input

## Methods and Techniques
- Step response analysis
- Linear regression for damping estimation
- Chirp-based frequency identification
- ARX, ARMAX, OE, BJ, IV4 models
- State-space models (N4SID, SSEST)
- Residual analysis and model validation

## Tools
- MATLAB
- Simulink
- System Identification Toolbox
